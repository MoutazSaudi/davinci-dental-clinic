# Design System

## Design Direction

Modern Medical Luxury.

The interface should feel:

- Modern
- Clean
- Professional
- Trustworthy
- Calm
- Premium
- Medical

Avoid:

- Excessive rounded cards
- Excessive shadows
- Excessive gradients
- Overuse of gold
- Visually crowded layouts
- Generic AI-generated dashboard aesthetics
- Excessive glassmorphism
- Huge decorative elements

## Color Strategy

Primary:
#0B3B5A

Use for:

- Main headings
- Navigation
- Primary buttons
- Important UI elements

Gold:
#C6A664

Use sparingly for:

- Accents
- Highlights
- Decorative lines
- Premium details
- Important visual emphasis

Teal:
#2B7A78

Use for:

- Secondary actions
- Medical/health accents
- Interactive states
- Status indicators

Mint:
#A8D5C6

Use mainly for:

- Soft backgrounds
- Sections
- Supporting visual elements

White:
#FFFFFF

Use as the dominant background.

---

## Typography

Arabic:

Cairo

English:

Inter

Typography should be:

- Clear
- Modern
- Highly readable
- Professional

Avoid decorative fonts.

---

## Layout

Use generous whitespace.

Prefer:

- Large visual hierarchy
- Clean sections
- Strong typography
- Consistent spacing
- Clear content grouping

Avoid:

- Dense layouts
- Unnecessary cards
- Excessive borders
- Excessive visual decoration

---

## Responsive Design

Every page must be designed for:

- Mobile
- Tablet
- Desktop
- Large desktop

Mobile is not an afterthought.

RTL and LTR must both work correctly.

Do not solve RTL using arbitrary negative margins or direction-specific hacks unless necessary.
